# The personal letter

Set the page on warm ivory paper with dark ink. A compact letterhead pairs Ivan’s headshot with his name and roles. The LinkedIn link sits across from the byline and wraps below it on small screens.

Use Georgia for the opening statement, bio, and headings. Italicize “automation” in rust. Keep the bio within 62 characters of measure and use the sans serif for project descriptions, action links, and small roles.

Separate the projects with fine horizontal rules. Align the name, description, and action in three columns. The whole row is a link. On narrow screens, move the description below the name and action. Rust underlines and visible keyboard focus identify actions.
