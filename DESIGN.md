# The personal letter

Set the page on cool off-white paper with dark ink. A compact letterhead pairs Ivan’s headshot with his name and roles. The LinkedIn link sits across from the name and wraps below it on small screens.

Use Georgia for the opening statement, bio, and headings. Italicize “automation” in rust. Cap the bio at 62ch, about 85 characters of Georgia per line, and use the sans serif for project descriptions, action links, and small roles.

Separate the projects with fine horizontal rules. Align the name, description, and action in three columns. The whole row is a link. On narrow screens, move the description below the name and action. Rust underlines and visible keyboard focus identify actions.
